## What came in from upstream

- **The Settings dialog is built in code.** Upstream replaced the Qt Designer
  `.ui` files and the generated `*_ui.py` files with these parts:
  - field specs in `gridplayer/params/settings_fields/`
  - a page layout in `gridplayer/params/settings_pages.py`
  - a shared paged dialog in `gridplayer/dialogs/paged_dialog.py`
  - an index with line icons
  - cards of rows, with section links on long pages
  - Reset beside each page title
  - a search over all settings
  - a check (`tests/test_settings_fields.py`) that every setting is shown
    exactly once
- **The Playlist window** combines Playlist Settings, Bookmarks and Lists.
  "Save all settings in the playlist" is new, and the Settings dialog marks
  which settings the open playlist keeps as its own.
- **View, aspect and crop.** Aspect is renamed View Mode, with the choices
  Fill, Fit and Stretch. Upstream adds:
  - VLC's Aspect Ratio presets and Crop presets, for one video or all of them
  - Default and Off over the shape a channel list gives
  - videos whose pixels are not square, which are now shown at their real
    shape (`VideoTrack.sar`, `pixel_aspect`)
- **About and crash dialogs** are built in code too.
- Fixes:
  - a paused hardware-decoded video stays black
  - "Video stopped unexpectedly" is logged when a video closes on Linux
  - several fixes to how settings are saved and inherited
  - the Windows build scripts

## How the Alabaster settings were ported to the new dialog

Each fork setting is now a field spec that is placed on a page. None of them
is a `.ui` widget any more.

- **SubtitleCat**
  - `gridplayer/params/settings_fields/plugins.py` (new, and listed in
    `registry.py`) has two fields:
    - `plugins/subtitlecat`: "Enable SubtitleCat"
    - `plugins/subtitlecat_translate`: "Request translations"
  - Neither field has an `enabled_when`. The fork's test requires
    translations to stay switchable while SubtitleCat is off.
  - `settings_pages.py` adds a new index group, **Plugins**, with one page,
    **SubtitleCat**. The page has:
    - its two switches
    - an **Account** section, whose `Slot("subtitlecat_account")` is filled by
      `SettingsDialog._slot_subtitlecat_account`. That method builds the
      **Sign up** and **Sign in** buttons (`subtitleCatSignUp` and
      `subtitleCatSignIn`).
    - the page note "Alabaster has no SubtitleCat account…"
  - The buttons open only the two fixed subtitlecat.com URLs.
    `_open_subtitlecat_page` refuses any other URL. They save nothing.
  - The page has a new icon, `page-plugins` (Lucide "puzzle"), in light and
    dark versions. It is listed in `resources/resources.csv`.
- **Warn above N cells:** `playlist/many_cells_count` is a number box,
  "Warn above … cells", from 2 to 100, with a default of 12. It is indented
  under "Warn about too many cells" and enabled only while that switch is
  on. It is also bound in `settings_bindings.PLAYLIST_ATTRS`, so a playlist
  can keep its own value.
- **Player page:** a new "Video and sound" section has these settings:
  - Rotate videos to fit their cells (`player/auto_rotate`)
  - the turn direction, indented under it
  - the volume step per wheel notch or key press (`player/volume_step`,
    1 to 25 %)
- **Cookies page:** this uses the fork's model. Cookies are only read from
  a browser for each request and are never stored.
  - `cookies/from_browser` is a list of yt-dlp's supported browsers in a
    preferred order, with "Off" as the first choice.
  - `cookies/browser_profile` sets the browser profile.
  - A "Privacy" note says that nothing is saved.
  - Upstream's stored-cookie list, its Import, Refresh and Allow-update
    controls, `cookies/enabled` and `cookies/allow_update` are all removed.
- **Link Resolution page, yt-dlp section:**
  - `streaming/js_runtime_allow_path` and `streaming/ytdlp_external_path`
    come after the YouTube test button.
  - The PATH impersonation warnings still appear when the PATH runtime is
    switched on or when an external yt-dlp path is typed.
- **Opening on a page:** `SettingsDialog(parent, page=...)` takes upstream's
  page ids and raises `ValueError` for an unknown id.
- **Index headings** use the Alabaster look: blue (`#2f8fe0`), bold,
  underlined and centred, at 17 px. They keep upstream's upper-case text,
  which upstream's tests require.

## Behavior choices

- **Aspect, crop and view mode:** upstream's model is kept as it is: View
  Mode, plus the Aspect Ratio and Crop presets, plus list shapes. The fork's
  Aspect filter (skip or ask about the other orientation while navigating)
  is a different feature and is kept.
- **Rotate to fit and the orientation filter use the shape that is shown.**
  - `utils/auto_rotate.py` and `utils/media_shape.py` take the pixel aspect
    (SAR), so a video with non-square pixels is judged by the shape it is
    shown at.
  - When an aspect ratio or crop is picked for a cell, or the list gives one,
    the user has chosen a shape. Rotate to fit then does not turn the cell,
    and turns back a turn it made itself.
  - `VideoBlockView.set_aspect_ratio` and `set_crop_ratio` ask Rotate to fit
    to look again.
  - `tests/test_auto_rotate_shapes.py` is a new test for this.
- **Video block guards** (`54eac57`): `sip.isdeleted()` is called only for
  real Qt objects. Any other object is treated as never closed. Upstream's
  new aspect, crop and list-shape tests use `Mock(spec=VideoBlock)` objects,
  and these had raised `TypeError`. The same change also clears the fork's
  140 or so long-standing "isdeleted … not Mock" failures.
  `tests/test_video_block_guards.py` checks both cases: a deleted Qt block
  is skipped, and a specced Mock is not.
- **Kept as the fork has them:**
  - The name GridPlayer Alabaster, version `0.5.5-alabaster.1`, its own
    settings folder (`GridPlayer-Alabaster`) and its own single-instance pipe
    (`gridplayer-alabaster-fileopen`)
  - The keymap: the loop keys `[` `]` `\`, Shift+N and Shift+B for a random
    file, and Ctrl+C to copy the file
  - `MAX_CELLS = 32`
  - Unsaved changes default to Discard
  - The paste throttle, UNC refusal, URL scheme allowlist and paste size caps
  - The seek scrub throttle
  - The pinned bundled yt-dlp, the vendored Deno, and PATH engines as an
    opt-in
  - The fork's default resolver (yt-dlp)
  - Tests use a temporary data folder (`tests/conftest.py`), and
    `tmp_path_retention_policy = "none"`
- **Upstream tests changed to fit the fork:**
  - `test_settings_reset`: "cookies stay" became "cookies go back to no
    browser".
  - `test_settings_search`: the note-with-rows case now uses the Cookies
    page's Privacy section. The "beside a list" case lost its Cookies entry,
    because that page has no list now.
  - `test_managers_settings`: the dialog stub accepts `page`, and the mocked
    dialog is not passed to `sip.delete`.

## Open risks

- Shapes in the `media_shape` cache were worked out before the SAR change.
  An old cache entry can have the wrong orientation for a video with
  non-square pixels until the cache is refreshed.
- A stream's SAR can arrive after the first Rotate-to-fit check. Upstream
  asks for it again as it arrives, but the turn is not checked again at that
  point.
- Upstream's Playlist window can keep `many_cells_count` per playlist. That
  has not been tried by hand.
