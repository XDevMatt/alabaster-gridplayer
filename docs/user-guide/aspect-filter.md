# Aspect filter

The aspect filter decides what a cell does with a file of the other
orientation (portrait in a landscape cell, or the other way round):

- **Play it** (default): no filtering.
- **Skip it**: move on to another file.
- **Ask**: ask what to do.

It can be set per cell and for all cells (`[ALL]`), with a default in
Settings and in the playlist.
