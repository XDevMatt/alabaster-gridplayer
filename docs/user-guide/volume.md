# Volume

You can set the volume for each cell on its own, or mute every cell at once.

New cells start muted, at 0%, so a full grid doesn't play every soundtrack at
once. To start cells with sound, turn off **Muted** in Settings, Defaults, New
Videos, Audio.

## Change a cell's volume

Point at a cell and scroll the mouse wheel:

- Scroll up to make it louder.
- Scroll down to make it quieter.

Only the cell under the pointer changes. The other cells keep their volume.

Each wheel notch changes the volume by 3%. The same step is used by the volume
keys and the menu items. To change it, use **Volume step per wheel notch or
key press** in Settings, General, Player (1% to 25%). Volume goes from 0% to
100%.

## Mute or unmute all cells

Press `M` to mute every cell. If every cell is already muted, `M` unmutes them
all.

## Mute one cell

Right-click the cell and choose **Audio > Mute** (it reads **Unmute** when the
cell is muted). This command has no key by default; you can give it one on the
Shortcuts page. Turning a cell down to 0% with the wheel also mutes it.

Mute is volume 0%. Nothing is kept behind it: unmuting, or scrolling up from
0%, goes to one step (3% by default), then 6%, and so on. If you want a mute
that keeps your level, use your system's or your speakers' mute.

## Play audio files

You can drop audio files on the grid like videos. A cell playing an audio file
shows an audio icon in place of a picture. Volume, seeking and the cell menu
work as for a video.

A folder you drop includes its audio files: every media file in it goes on the
list. **Files to play** set to **Videos only** (the default) also includes
audio files; it leaves out only pictures. See
[Choose which files play](playlists.md#choose-which-files-play).

For all volume keys, see [Hotkeys](../reference/hotkeys.md).
