# New cells

Every cell you add starts from the **New Videos** defaults in Settings,
Defaults, New Videos. A saved playlist keeps each cell's own values (see
[Per-cell settings](profiles.md)).

The ones you'll notice first:

| Default | Value | Change it at |
| --- | --- | --- |
| **Muted** | On: new cells start at 0% | New Videos, Audio, **Muted** |
| **Volume** | 100%, used only when Muted is off | New Videos, Audio, **Volume** |
| **When finished** | Loop this file | New Videos, Playback |
| **Include subfolders** | On | New Videos, Playback |
| **Files to play** | Videos only | New Videos, Playback |
| **Other orientation** | Play it | New Videos, Playback |
| **Slide duration** | 10 seconds | New Videos, Playback |
| **Initial state** | Playing | New Videos, Playback |
| **View mode** | Fill (covers the cell, cutting edges) | New Videos, Video |
| **Subtitles** | Off | New Videos, Subtitles |

## Why muted?

A grid of nine videos all playing sound at once isn't useful. Scroll up over
the cell you want to hear, or press `M` to unmute every cell. Unmuting
starts at one volume step (3%), not where you were: mute is 0%. See
[Volume](volume.md).

To start cells with sound, turn **Muted** off. A playlist saved with a muted
cell still opens that cell muted.

## A cell made from a folder or list

A cell made to play a folder or list goes on along it at the end of each
file (**Play next file**), whatever **When finished** says for single files.
At the end of the list it does what **When list ends** says (default:
**Start over**).
