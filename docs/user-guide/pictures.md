# Pictures

Pictures play as slides: each one is shown for the cell's **Slide duration**,
then the cell's **When Finished** action runs, just as at the end of a video.
An animated GIF plays as VLC plays it.

Supported extensions: `jpg`, `jpeg`, `jpe`, `jfif`, `png`, `webp`, `gif`,
`bmp`, `tif`, `tiff`.

## Slide duration

From 1 to 3600 seconds, default 10. Set the default in Settings, Defaults,
New Videos, Playback, **Slide duration**. For one cell, right-click,
**Playback > Slide Duration** (3, 5, 10, 15, 30 or 60 seconds).

## Make a slideshow

1. Set the cell's **Files to Play** to **Images only** (or **All media** to
   mix pictures with videos).
2. Set **When Finished** to **Play next file** or **Play random file**. With
   the default, **Loop this file**, the cell keeps showing the same picture.
3. Drop a picture from the folder, or the folder itself.

## Files to Play

Chooses what a cell plays when it steps through a folder:

- **Videos only** (default)
- **All media** (videos, audio and pictures)
- **Images only**

It can be set per cell and for all cells (`[ALL]`). A picture you drop on the
window is still opened, whatever this is set to.
