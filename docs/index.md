# GridPlayer Alabaster

**Alabaster 0.2beta - (from GridPlayer 0.5.5)**

GridPlayer Alabaster is a multi-cell video player: it plays many videos side by
side in a grid, each cell with its own file, position, loop and volume. Playback
uses VLC (libVLC) through a Python / PyQt5 interface.

Alabaster is its own project. It was built using
[GridPlayer](https://github.com/vzhd1701/gridplayer) by vzhd1701 as its
framework, starting from GridPlayer 0.5.5. Many thanks to vzhd1701 for
GridPlayer, which made this project possible. GridPlayer is licensed under the
GNU GPL v3, and Alabaster is distributed under the same terms; see `NOTICE` and
`LICENSE` in the repository.

Alabaster keeps its own settings folder (`GridPlayer-Alabaster`), so it can be
installed next to upstream GridPlayer without sharing settings.
