# GridPlayer Alabaster

## Alabaster 0.2beta - (from GridPlayer 0.5.5)

GridPlayer Alabaster is a Windows multi-cell video player: it plays many
videos side by side in a grid, each cell with its own file, position, loop and
volume. Playback uses VLC (libVLC) through a Python / PyQt5 interface.

Alabaster is a modified version of
[GridPlayer](https://github.com/vzhd1701/gridplayer) 0.5.5 by Vlad
(vzhd1701). Many thanks to Vlad for GridPlayer, which made this project
possible. GridPlayer is licensed under the GNU GPL v3, and Alabaster is
distributed under the same terms; see `NOTICE` and `LICENSE` in the
repository. Alabaster is not the official GridPlayer and is not on PyPI.

Alabaster supports Windows 10 and 11 only. It keeps its own settings folder
(`GridPlayer-Alabaster`), so it can be installed next to upstream GridPlayer
without sharing settings.
